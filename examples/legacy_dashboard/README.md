# Dashboard demo cũ

Các tệp ở đây là ví dụ SQLite độc lập từ phiên bản Dashboard trước. Dashboard hiện tại dùng `dashboard/backend/main.py` và đọc `data/pull_requests.json`; không cần chạy `seed.py` để dùng ứng dụng chính.

Nếu muốn chạy thử ví dụ cũ, cài `requirements.txt` trong thư mục này rồi chạy `seed.py` từ chính thư mục này. Tệp `pr_dashboard.db` sinh ra là dữ liệu cục bộ và được Git bỏ qua.
